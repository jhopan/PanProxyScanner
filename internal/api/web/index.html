Alur yang disarankan

  1. Aplikasi ini yang melakukan verifikasi (handshake nyata) — panel CFVPN Hub cukup membaca tabel.
  2. Push sekarang: proxy hidup & segar dari database lokal dikirim ke tabel Supabase (upsert by ip,port, kolom is_active, ping, last_checked, country).
  3. Tarik & verifikasi: baris lama dari Supabase diambil, diuji satu per satu di sini, lalu ditulis balik — jadi daftar di Supabase tidak berisi proxy mati.
  4. Nyalakan otomatis dorong + isi tarik & verifikasi per siklus supaya panel selalu menerima daftar segar tanpa menambah bandwidth browser.

Langkah pipeline

belum pernah dijalankan
Urutan: tarik dari Supabase → uji satu per satu → simpan → scrape sumber → simpan → push ke Supabase. Verdict ditulis per batch (hidup = upsert, mati = satu PATCH per 200 id) supaya request ke Supabase tetap sedikit.

Endpoint

POST /api/login — masuk (body {"username","password"}, cookie sesi)
POST /api/logout · GET /api/me
GET /api/proxies · GET /api/proxies.txt — filter alive, protocol, country, tls, alt, max_ping, min_sources, fresh_minutes, limit, offset, order
GET /api/countries — jumlah per negara
GET /api/stats · GET /api/health (publik)
GET/POST /api/settings — pengaturan (termasuk akun admin, token, public URL)
POST /api/auto/start · /api/auto/stop · /api/now · /api/stop
POST /api/scrape?cap=&offset=&jobs=&min_sources= · POST /api/purge?hours=24
GET /api/vless/clash?host=&uuid=&port=443 · GET /api/vless/raw?host=&uuid=
GET /api/tunnel — status Cloudflare + perintah cloudflared
Klien mesin (panel CFVPN Hub) memakai X-Api-Token: <token> atau ?token=; browser memakai cookie sesi.

Contoh

curl -X POST http://127.0.0.1:8787/api/login -H "Content-Type: application/json" -d '{"username":"admin","password":"admin"}'
curl "http://127.0.0.1:8787/api/proxies.txt?max_ping=2000&country=SG,ID&limit=50"
curl -o vless.yaml "http://127.0.0.1:8787/api/vless/clash?host=<worker>.workers.dev&uuid=<uuid>&limit=100"
curl -X POST "http://127.0.0.1:8787/api/settings" -H "X-Api-Token: <token>" -H "Content-Type: application/json" -d '{"auto":true,"interval_minutes":15}'
